# Archivo histórico

Esta carpeta contiene material que ya no forma parte del flujo operativo:

- `legacy-notes/`: instrucciones, parches y hotfixes acumulados.
- `legacy-site-source/`: antigua fuente Quarto; se eliminaron sus cachés generadas.
- `legacy-site-assets/`: CSS y JavaScript reemplazados.
- `legacy-build-scripts/`: launchers y scripts de publicación obsoletos.

No debe usarse como fuente para editar el sitio ni para ejecutar actualizaciones. Se conserva únicamente para trazabilidad y comparación histórica.
