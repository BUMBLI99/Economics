Nowcasting de actividad económica en Chile

Modelo mensual en R para seguimiento coyuntural del IMACEC total y no minero

NotaEstado del proyecto

Proyecto aplicado en desarrollo continuo. La metodología base está implementada para actualizarse mensualmente con nueva información. La página está pensada como una vitrina técnica: muestra la motivación, la estructura del modelo, los resultados principales y el pipeline reproducible.

Pregunta económica

El IMACEC es una de las señales principales para evaluar la coyuntura económica chilena. Este proyecto busca responder una pregunta práctica:

¿Es posible anticipar la evolución reciente del IMACEC total y no minero usando información mensual disponible antes de la publicación oficial?

El objetivo no es producir una proyección oficial, sino construir una herramienta reproducible de seguimiento coyuntural que combine datos macroeconómicos, variables calendario, indicadores sectoriales y modelos econométricos simples.

Datos utilizados

El pipeline integra información mensual de actividad, comercio, crédito, precios, mercado laboral e indicadores sectoriales. La versión actual considera:

  • IMACEC total e IMACEC no minero.
  • Ventas minoristas.
  • Flujo y número de operaciones de crédito.
  • UF e inflación implícita asociada.
  • Desempleo.
  • Cobre y petróleo.
  • Días hábiles y variables calendario.
  • Indicadores sectoriales INE: minería, manufactura, comercio y electricidad.

Enfoque metodológico

La versión actual estima dos familias de modelos lineales de nowcasting:

  1. Modelo con estadísticas experimentales: usa rezagos de actividad, ventas minoristas, crédito, UF y controles calendario.
  2. Modelo con indicadores sectoriales INE: agrega minería, manufactura, comercio, electricidad y desempleo, cuando esos datos están disponibles.

El modelo publicado como nowcast activo es el de indicadores sectoriales INE cuando puede estimarse correctamente; en caso contrario, el pipeline puede usar la especificación de estadísticas experimentales. Para la evaluación, ambos aparecen como modelos separados frente a benchmarks simples.

Evaluación pseudo out-of-sample contra benchmarks simples

La evaluación no usa una fecha arbitraria fija en el código de la página. Por defecto se calcula desde 2022-01, pero el inicio puede cambiarse con la variable de entorno:

IMACEC_EVAL_START_DATE=2022-01-01

Se comparan ambos modelos contra reglas simples:

  • Benchmark AR(1): modelo autoregresivo de un rezago sobre la variación anual del IMACEC.
  • Promedio móvil 3m: promedio de las últimas tres variaciones anuales observadas.
  • Naive estacional t-12: se reutiliza la variación anual observada doce meses antes.

NotaCómo leer esta tabla

La comparación relevante no es si el modelo tiene error bajo en términos absolutos, sino si reduce RMSE/MAE frente a reglas simples. Si el promedio móvil o el AR(1) dominan al modelo, eso sugiere que la persistencia reciente explica buena parte de la dinámica y que los indicadores adicionales deben ser revisados o usados con una especificación más parsimoniosa.

Esta evaluación es pseudo out-of-sample recursiva con datos finales disponibles. No reemplaza una evaluación con vintages en tiempo real.

ImportanteLectura prudente

Las métricas anteriores corresponden a ajuste interno del modelo. La evaluación pseudo out-of-sample es más informativa para juzgar desempeño predictivo, aunque todavía no representa una evaluación en tiempo real con vintages de publicación.

Próximos pasos

  • Separar formalmente una versión de nowcast temprano y otra de nowcast con indicadores sectoriales completos.
  • Incorporar fechas efectivas de publicación de cada indicador para una evaluación más realista en tiempo real.
  • Probar especificaciones más parsimoniosas: AR(1) + calendario, AR(1) + sectores clave y combinaciones de modelos.
  • Incorporar intervalos de predicción calibrados con errores pseudo out-of-sample.
  • Automatizar actualización mensual con GitHub Actions.
