Pregunta económica

El IMACEC es una de las señales principales para evaluar la coyuntura económica chilena. Este proyecto busca responder una pregunta práctica:

¿Cuánto se puede anticipar el IMACEC total y no minero antes de la publicación oficial, usando la información que aparece durante el mes?

La idea no es producir una proyección oficial, sino construir una herramienta reproducible de seguimiento coyuntural. La gracia del ejercicio está en respetar el calendario de publicación: el modelo temprano no debería usar variables que aún no están disponibles, y el modelo con indicadores sectoriales INE solo debería entrar cuando esas series ya fueron publicadas.

Flujo de vintages

La página sigue el ciclo efectivo de publicación de información:

  1. Dato oficial recién publicado: cuando aparece el IMACEC efectivo de un mes, la página conserva ese ciclo cerrado. En el gráfico se muestran el dato observado, la estimación propia que habría estado disponible con el último vintage y la EEE si existía para ese mes.
  2. EEE del siguiente mes: cuando se publica la encuesta para el IMACEC de un mes atrás, se abre el nuevo ciclo de nowcast. En esta etapa se usa la EEE para el IMACEC total y supuestos simples para variables contemporáneas todavía no publicadas.
  3. Indicadores experimentales/BCCh: cuando aparecen ventas, crédito u otras señales mensuales, se actualiza la estimación propia con esa información. La EEE se mantiene en el gráfico como punto de comparación, no desaparece.
  4. Indicadores sectoriales INE: cuando se publican minería, manufactura, comercio, electricidad y mercado laboral, se usa el vintage más informado. La página conserva simultáneamente la estimación propia y la EEE.
  5. Nuevo dato oficial: al publicarse el IMACEC efectivo, se agrega el punto observado y se mantiene la comparación hasta que la EEE del siguiente mes abra el nuevo ciclo.

Datos utilizados

El proyecto integra información mensual de actividad, comercio, crédito, precios, mercado laboral e indicadores sectoriales. La versión actual considera:

  • IMACEC total e IMACEC no minero.
  • EEE de IMACEC total, alineada al mes proyectado.
  • Ventas minoristas.
  • Flujo y número de operaciones de crédito.
  • UF e inflación implícita asociada.
  • Desempleo.
  • Cobre y petróleo.
  • Días hábiles y variables calendario.
  • Indicadores sectoriales INE: minería, manufactura, comercio y electricidad.

Enfoque metodológico

El modelo no es único durante todo el mes. Cambia según el set de información disponible para el período objetivo:

  • antes de contar con indicadores contemporáneos completos, la EEE entrega una señal directa para el IMACEC total;
  • con indicadores experimentales y financieros ya publicados, el modelo actualiza la señal usando actividad, crédito, comercio, UF y calendario;
  • tras la publicación de los indicadores sectoriales INE, se usa la especificación más informada, incorporando minería, manufactura, comercio, electricidad y desempleo rezagado.

Esta organización replica mejor el problema real de nowcasting: no se trata solo de estimar una regresión, sino de actualizar la proyección cuando llega nueva información.

ImportanteLectura prudente

Las métricas anteriores corresponden a ajuste interno del modelo. Sirven para verificar si el ajuste reproduce razonablemente la muestra histórica, pero no deben interpretarse como desempeño predictivo real. Por eso se agrega una evaluación pseudo out-of-sample contra benchmarks simples.

Evaluación pseudo out-of-sample y benchmarks simples

La evaluación fuera de muestra re-estima el modelo con una ventana expansiva: para cada fecha de evaluación, se usa solo información disponible hasta el mes anterior. La predicción se compara contra tres reglas simples:

  • Benchmark AR(1): modelo autoregresivo de un rezago sobre la variación anual del IMACEC.
  • Promedio móvil 3m: promedio de las últimas tres variaciones anuales observadas.
  • Naive estacional t-12: se reutiliza la variación anual observada doce meses antes.

NotaCómo leer esta tabla

La comparación relevante no es si el modelo tiene error bajo en términos absolutos, sino si reduce RMSE/MAE frente a reglas simples. Si el promedio móvil o el AR(1) dominan al modelo principal, eso es una señal útil: el modelo necesita simplificación, mejores predictores contemporáneos, mejor tratamiento de vintages o una ventana de estimación distinta.

La ventana de evaluación todavía es corta; por lo tanto, estos resultados deben leerse como diagnóstico preliminar de desempeño predictivo, no como validación definitiva del modelo.

Próximos pasos

  • Separar formalmente los vintages de publicación usando calendarios efectivos de cada serie.
  • Guardar y comparar proyecciones históricas con más de un corte mensual.
  • Incorporar intervalos de predicción calibrados con errores fuera de muestra.
  • Evaluar especificaciones más parsimoniosas frente a modelos con muchos predictores contemporáneos.
