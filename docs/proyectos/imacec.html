Nowcasting de actividad económica en Chile

Modelo mensual en R para seguimiento coyuntural del IMACEC total y no minero

NotaEstado del proyecto

Proyecto aplicado en desarrollo continuo. La metodología base está implementada para actualizarse mensualmente con nueva información. La página muestra el resultado publicado, la fuente activa del nowcast, la evaluación contra benchmarks simples y el pipeline reproducible.

Pregunta económica

El IMACEC es una de las señales principales para evaluar la coyuntura económica chilena. Este proyecto busca responder una pregunta práctica:

¿Es posible anticipar la evolución reciente del IMACEC total y no minero usando información mensual disponible antes de la publicación oficial?

El objetivo no es producir una proyección oficial, sino construir una herramienta reproducible de seguimiento coyuntural que combine datos macroeconómicos, variables calendario, indicadores sectoriales, expectativas y modelos econométricos simples.

Datos utilizados

El pipeline integra información mensual de actividad, comercio, crédito, precios, mercado laboral, expectativas y datos sectoriales. La versión actual distingue explícitamente tres niveles de información:

  • EEE: fuente temprana para el mes objetivo cuando aún no existen indicadores sectoriales completos.
  • Estadísticas experimentales: rezagos de actividad, ventas minoristas, crédito, UF y controles calendario.
  • Indicadores sectoriales INE: minería, manufactura, comercio, electricidad y desempleo cuando ya están disponibles para el mes objetivo.

Enfoque metodológico

La versión actual estima dos familias de modelos lineales de nowcasting:

  1. Modelo con estadísticas experimentales: usa rezagos de actividad, ventas minoristas, crédito, UF y controles calendario.
  2. Modelo con indicadores sectoriales INE: agrega minería, manufactura, comercio, electricidad y desempleo, pero solo se publica como nowcast activo cuando esos indicadores existen para el mes objetivo.

La regla de publicación es:

Indicadores sectoriales INE completos → Modelo INE
Si no están completos y existe EEE → EEE
Si no existe EEE y hay estadísticas experimentales completas → Modelo experimental
Último recurso → modelo preliminar con supuestos de arrastre

Evaluación pseudo out-of-sample contra benchmarks simples

La evaluación se calcula desde 2022-01 por defecto. Puede cambiarse con la variable de entorno IMACEC_EVAL_START_DATE antes de correr el script.

Se comparan ambos modelos contra reglas simples:

  • Benchmark AR(1): modelo autorregresivo de un rezago sobre la variación anual del IMACEC.
  • Promedio móvil 3m: promedio de las últimas tres variaciones anuales observadas.
  • Naive estacional t-12: se reutiliza la variación anual observada doce meses antes.

NotaCómo leer esta tabla

La comparación relevante no es si el modelo tiene error bajo en términos absolutos, sino si reduce RMSE/MAE frente a reglas simples. Si el promedio móvil o el AR(1) dominan al modelo, eso sugiere que la persistencia reciente explica buena parte de la dinámica y que los indicadores adicionales deben revisarse o usarse con una especificación más parsimoniosa.

Esta evaluación es pseudo out-of-sample recursiva con datos finales disponibles. No reemplaza una evaluación con vintages en tiempo real.

ImportanteLectura prudente

Las métricas anteriores corresponden a ajuste interno del modelo. La evaluación pseudo out-of-sample es más informativa para juzgar desempeño predictivo, aunque todavía no representa una evaluación en tiempo real con vintages de publicación.

Próximos pasos

  • Separar formalmente una versión de nowcast temprano y otra de nowcast con indicadores sectoriales completos.
  • Incorporar fechas efectivas de publicación de cada indicador para una evaluación más realista en tiempo real.
  • Probar especificaciones más parsimoniosas: AR(1) + calendario, AR(1) + sectores clave y combinaciones de modelos.
  • Incorporar intervalos de predicción calibrados con errores pseudo out-of-sample.
