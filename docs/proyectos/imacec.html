Nowcasting de actividad económica en Chile

Seguimiento mensual del IMACEC total y no minero con EEE, modelo base, modelo INE y dato efectivo

NotaEstado del proyecto

Proyecto aplicado en desarrollo continuo. La página está organizada para seguir el flujo mensual del IMACEC en el orden en que llega la información: EEE → modelo base con estadísticas experimentales → modelo INE → dato efectivo.

Pregunta económica

El IMACEC es una de las señales más importantes para monitorear la coyuntura chilena. El objetivo de este proyecto es responder una pregunta práctica:

¿Cuánto se puede anticipar el IMACEC total y el IMACEC no minero antes de que aparezca la publicación oficial?

La lógica de la página no es mostrar un único ajuste histórico, sino el ciclo de publicación del nowcast: primero la EEE, luego el modelo base cuando ya existen estadísticas experimentales, después el modelo INE cuando entran los datos sectoriales, y finalmente el dato efectivo.

Flujo del proyecto

1. Al cerrarse un mes con dato oficial, el IMACEC efectivo pasa a la base de estimación y el ciclo vuelve a empezar para el mes siguiente.

2. Cuando se publica la EEE, se incorpora como primera señal del nuevo mes objetivo. En esta etapa se compara la EEE con el dato efectivo del mes anterior y queda publicada como referencia temprana.

3. Cuando llegan las estadísticas experimentales (alrededor del día hábil cercano al 23), se activa el modelo base y se compara nuevamente con la EEE.

4. Cuando se publican los indicadores sectoriales INE, se activa el modelo INE, que reemplaza al modelo base como señal más rica del mes objetivo.

5. Cuando aparece el IMACEC efectivo, se agrega el dato observado, se evalúa el error de las señales previas y el ciclo recomienza para el siguiente mes.

Datos utilizados

El pipeline combina cuatro bloques de información:

  • Dato efectivo: publicación oficial del Banco Central para el IMACEC total y no minero.
  • EEE: primera señal del mes objetivo, publicada con rezago de un mes respecto del período proyectado.
  • Modelo base: rezagos de actividad, ventas minoristas, crédito, UF y variables calendario.
  • Modelo INE: agrega minería, manufactura, comercio, electricidad y desempleo cuando esos indicadores existen efectivamente para el mes objetivo.

NotaCómo leer la evaluación

La pregunta relevante no es si el modelo tiene un error bajo en abstracto, sino si mejora de manera sistemática a benchmarks simples. Si el promedio móvil o el AR(1) empatan o dominan al modelo, eso sugiere que la información adicional todavía no está agregando suficiente señal predictiva.
